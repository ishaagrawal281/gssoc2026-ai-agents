
# Dataset Contributions

This folder documents dataset contributions created during GSSoC 2026.

## Planned Dataset Areas

Potential datasets may support:

- Technical interview questions
- AI-agent evaluation examples
- Indian-language/localization examples
- Student-oriented AI use cases

## Quality Principles

Datasets should be:

- Relevant
- Consistent
- Clearly structured
- High quality
- Free from private or sensitive information
- Validated before submission
